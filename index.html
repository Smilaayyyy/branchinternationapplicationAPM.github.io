Bank verification and multi-account selection

Highest priority

Issue today

Users can type wrong account details and the app carries them all the way to the final confirmation page before anything fails. The error lands after the most effort has been spent.

Fix

Fetch the accounts linked to the user’s phone number, let them tap one, and verify the holder name against Aadhaar or PAN on the same screen. A mismatch stops the flow right there.

Framework

Fetch (AA / UPI)→Select tile→Verify name→Verified
  • Name match score of 0.85 or higher passes, anything lower is a hard stop.
  • API failures show a neutral retry banner, never a mismatch message.
  • The confirmation page only accepts accounts in the verified state.
  • Three failed attempts in 24 hours triggers a 30-minute cool-down.

Try: select a tile and continue, then use “My account isn’t listed”.

DigiLocker fallback and automated parsing

Medium priority

Issue today

When the DigiLocker bridge stalls, times out or the user forgets their PIN, there is no way out and people abandon onboarding.

Fix

A latency listener watches the WebView. After 15 seconds without progress, or the moment “Forgot PIN” is tapped, an optional sheet offers a photo of the card. On-device OCR reads it.

Framework

DigiLocker loads→15 s listener→Stall sheet→Camera + OCR→Review
  • The WebView stays alive and the sheet dismisses itself if DigiLocker recovers.
  • “Keep waiting” restarts the listener once with a 30 second window.
  • Fields under 0.90 confidence are flagged amber for review.
  • Photos are processed on the device and not uploaded by default.

Aadhaar input masking

Friction polish

Issue today

Three separate boxes treat each segment edge as a forced tab. Press Backspace in an empty box and focus jumps back, then auto-advances forward again. The cursor loops.

Fix

One continuous field that formats as #### #### ####. The spaces are display only, the value is 12 digits, and the caret stays on the same digit while you edit.

Framework

Strip non-digits→Cap at 12→Format→Restore caret→Verhoeff check
  • First digit must be 2 to 9.
  • Paste cleans separators automatically.
  • Errors are specific: the digit count, or a checksum warning.
  • The number is never logged, and the screen blocks screenshots.
